## Contrato de tests (obligatorio en el PR)

Archivos sugeridos: `tests/unit/test_search_filters.py`, CLI search dry-run con fixtures (sin red).

1. **`--dry-run`:** `torre search` / `getonboard search` / `jobs search` sobre fixture no escribe base, JSON ni `companies.yaml`; imprime decisión + motivo por fila.
2. **`exclude_title_terms`:** descarta título que contiene el término con motivo estable «título excluido».
3. **`min_salary`:** renta publicada bajo el mínimo → drop; sin renta publicada → keep marcado «renta no publicada».
4. **Sin `search_filters`:** mismo conjunto guardable que hoy (regresión).
5. **`--dry-run --store`:** exit 2, sin request.
6. **Confirm «no»** en TTY interactivo: no guarda; exit 130.
7. **`profile validate`:** moneda desconocida o `remote_from` sin país → rechazo.

## Justificación

Guardar todo lo que devuelve la fuente mezcla Preferencia con Fact y satura el SST. Un filtro tipado + dry-run hace auditable *por qué* un aviso no entró, sin inventar ubicación ni renta.
