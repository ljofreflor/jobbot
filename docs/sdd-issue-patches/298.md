## Contrato de tests (obligatorio en el PR)

Archivo sugerido: `tests/unit/test_companies_latam_seed.py` (+ ampliar oneshot/load_seeds).

1. **Seed cargable:** `data/companies-latam.seed.yaml` (trackeado) lo lee `load_seeds` / `companies discover` sin error; entradas tienen nombre + dominio público (sin PII).
2. **Sin inventar ATS:** un seed sin evidencia técnica queda `ats: unknown` (o equivalente) tras discover; nunca se fuerza Greenhouse/Workday por nombre.
3. **Bolsa omitida:** hint que apunta solo a laborum/computrabajo/… **no** se registra como career site de la empresa (#183).
4. **Dedup:** empleador ya en shared o seed CL no se duplica al importar el mismo batch (asserción por company_id / URL canónica).
5. **403/robots:** probe refused/omitted se reporta como tal; no como «sin portal».
6. **Offline:** fixtures de HTML/robots; sin red en unit; promote sigue siendo HITL (no auto-active).

## Justificación

El mapa LATAM es el diferenciador (#266); crecer solo el seed Chile deja fuera fintech/regional. El pipeline ya existe; este issue es el **barrido por batches** con contratos que impiden inventar ATS o promover bolsas. Shared + seed versionables; `companies.yaml` local gitignored.
