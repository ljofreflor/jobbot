## Contrato de tests (obligatorio en el PR)

Archivo sugerido: `tests/unit/test_indeed_apply_attach.py` (fixture HTML / page falsa; sin Playwright real ni red).

1. **Input CV + PDF del aviso:** un fixture con input de currículum y `output/jobs/J0001/application/cv.pdf` (o `cv.pdf`) deja ese path en el input falso; **cero** clics en Enviar / Postular / Submit.
2. **Sin PDF del aviso:** no hay upload; el mensaje nombra la ruta esperada (`output/jobs/J0001/cv.pdf` o la documentada); no se inventa otro archivo.
3. **Input de carta / cover letter:** no recibe el PDF del CV.
4. **Gate `page_asks_for_cv`:** si es falso, `attach_cv` no llama a `set_input_files`.
5. **Offline:** sin CDP real; CAPTCHA/2FA/términos y Siguiente (#412 / #188) fuera de alcance.

## Justificación

Clasificar si el paso pide CV y conocer `tailored_cv_path` no basta: el adapter aún no sube el archivo. El contrato es el mismo que Gmail compose (# email attach): poner el PDF conocido, nunca Send.
