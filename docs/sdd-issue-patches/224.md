## Contrato de tests (obligatorio en el PR / hijos)

Fixtures por plataforma bajo `tests/fixtures/{un_careers,pageup,…}/` (anonimizados); un `test_<plataforma>_source.py` por hijo; sin red.

1. **Fixture → JobPosting:** cada fuente habilitada produce título, organismo, ubicación/remoto, URL canónica, `closes_at` si viene en el aviso.
2. **Dedupe:** `source` + `source_job_id` (p. ej. guid RSS UN Careers); segunda corrida no duplica.
3. **PageUp id:** `/en-us/job/{id}/` → id estable; URL canónica sin slug de tracking.
4. **PDF:** capa de texto → aviso guardado; escaneado sin texto → fallo claro, no aviso vacío.
5. **Dry-run:** no escribe DB ni `companies.yaml`.
6. **Blocked:** Devex/IICA/UNjobs (y las que cierren blocked) → mensaje + exit 2, cero sockets.
7. **Robots / rate:** Disallow no se pide; UA identificable; Crawl-delay con reloj simulado.
8. **Cierre:** closed / `closes_at` vencido no se guarda como vigente (#207).
9. **Domain-agnostic:** `test_domain_agnostic` verde; queries del perfil, no vocabulario de oficio.

## Justificación

Perfiles no técnicos e internacionales dependen de RSS/HTML/PDF que #180/#191 no cubren. Una épica tipa el contrato común (Factory + blocked + SearchOutcome); los hijos implementan o declaran bloqueo sin inventar scrape tras login ni OCR.
