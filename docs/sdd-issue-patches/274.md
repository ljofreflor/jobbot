## Contrato de tests (obligatorio al cerrar)

No hay tests de código ni checklist Terraform. Cierre = respuestas escritas a las preguntas del issue.

1. **Operador:** quién administra la VM queda nombrado.
2. **SoT:** `profile.yaml` vive en esa máquina, nunca en git ni en almacén compartido de CV.
3. **Acceso:** cómo llega quien paga (Flutter de #272 = cliente, no la nube) queda acotado; prototipo después.
4. **Cobro:** separado de contraseñas/OTP; códigos siguen humanos.
5. **Límites:** ninguna respuesta pide multi-tenant PII, telemetría, stealth, proxies, ni browser datacenter disfrazado de hogar.
6. **Bloqueo:** diseño de correo de identidad (#272) no arranca hasta que lo anterior esté escrito.

## Justificación

Antes del buzón de #272 hace falta registrar la frontera de aislamiento: una máquina por cliente que paga, PII en esa máquina, IP de datacenter como límite medido (no rodeado). Es Decision Record + Isolation Boundary, no un JobBot Cloud multi-tenant.
