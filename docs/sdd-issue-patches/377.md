## Contrato de tests (obligatorio en el PR)

Archivo sugerido: `tests/unit/test_hiringroom_discover.py` (fetcher falso; sin red).

1. **Dry-run total:** fetcher con dos páginas y total «N-M de 31 vacantes» + `--dry-run` → muestra **31** filas y **no** escribe la base / `output/jobs`.
2. **Detalle cacheado:** un aviso ya guardado **no** vuelve a pedir su URL de detalle.
3. **Aislamiento:** un portal en **503** y otro sano → se guardan los del sano y el comando sale **0** (el 503 no tumba la corrida).
4. **`--site` inválido:** host que no es subdominio `*.hiringroom.com` → exit **2**.
5. **Tope:** para al llegar al total del listado o a `--limit`.

## Justificación

La página 2 es JS sin endpoint conocido (#377 fuera: adivinarlo). Exigir fixture de página 2 evita un crawler que invente query params (`?page=` / `?offset=` no sirven). El parse de ficha guardada (#243) ya existe; discover es el puerto que falta, con el mismo aislamiento multi-site que el resto de `jobs discover`.
