Docs / política, no provisioning.

2. **#106** sigue siendo el primer corte de federación (merge por archivos, sin servidor).

4. **Si GCP aparece:** solo bucket de `companies export` (lectura pública, escritura mantenedor, `pii_guard` en el borde) — después de que #106 duela.

## Justificación

Misma pregunta que vuelve: ¿metemos GCP bajo JobBot? La respuesta tipada es Bounded Context — el viajero no se hospeda; el mapa puede vivir en git y, si acaso, en un bucket sin PII.
