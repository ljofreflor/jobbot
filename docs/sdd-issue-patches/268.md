## Contrato de tests (obligatorio en el PR)

Archivo sugerido: `tests/unit/test_catalog_unknown_recon.py` + fixtures HTML (sin red).

1. **Lista por impacto:** canales `ats_family=unknown` ordenados por #empleadores; dry-run no escribe.
2. **Evidencia técnica:** fixture con redirect / marcador HTML → familia escrita + observación con URL; sin evidencia → sigue `unknown`.
3. **Hostname solo:** host genérico sin regla/marker → no inventa familia.
4. **Refused:** 403 / timeout / `robots` Disallow → se registra como no leído; el contador `unknown` no baja.
5. **Cobertura:** `portals catalog coverage` refleja el cambio sin alterar el denominador de canales.
6. **Identificar ≠ habilitar:** `unknown` → `trabajando` mueve a «pendiente de adaptador», no a «alcanzable» / auto-active.
7. **Seguridad:** recon no crea cuentas ni postula; contradicción → `stale`.

## Justificación

El 36,9% del catálogo CL sin plataforma no se desbloquea con un adaptador: primero hay que *saber* qué lo sirve. Reusar `#45` con evidencia tipada evita inventar ATS y reordena el ranking de desbloqueo solo cuando la observación es auditable.
