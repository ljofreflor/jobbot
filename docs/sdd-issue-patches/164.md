## Contrato de tests (obligatorio al cerrar)

Docs / issues hermanos.

1. **`docs/prior-art.md`** lista los homónimos con una línea y puntero a este issue.
2. **Ningún issue nuevo** pide autopilot, extensión con visión, ni hospedar el CV.
3. **Huecos reales** quedan en issues ya abiertos (#33, #34, #84, #32 enriquecido, #154) — no un tracker paralelo.
4. **Primer corte cuando priorice:** gap transferable vs genuine → #84 cold start → #33 carta HITL solo si el mantenedor la necesita (sigue parked de tesis).
5. **Dominio-agnóstico:** ESCO u otra taxonomía no es gate de matching.

## Justificación

Varios productos se llaman JobBot; no peleamos la marca (#261). Robamos outcomes (CV sin inventar, gaps honestos, digest de cola HITL) con el mismo filtro que #155: nunca el medio de autopilot.
