## SDD / patrones

- **SDD:** `docs/software-design.md` §3.1 `JobSourceAdapter` · config local (no PII en git) · polite rate limit · never invent
- **Patrón(es):** **JobSourceAdapter** `ReliefWebDiscover` (API JSON v2 `POST …/v2/jobs?appname=`); **Config Port** `[sources.reliefweb].appname` / `JOBBOT_RELIEFWEB_APPNAME` (env gana; valor **nunca** en logs); **Guard** sin appname → exit `AUTH_REQUIRED` (3) sin red; paginación por `offset` hasta `totalCount` / `--limit`
- **UML:** [`docs/uml.md#reliefweb-discover`](../uml.md#reliefweb-discover) · [`ports`](../uml.md#ports) · [`search-outcome`](../uml.md#search-outcome)
- **Cambio de diagrama:** el PR tipa el adapter + resolución de appname y actualiza `reliefweb-discover`

## Contrato de tests (obligatorio en el PR)

Archivos sugeridos: `tests/unit/test_reliefweb_source.py`, fixtures en `tests/fixtures/reliefweb/` (sin appname real); ampliar `test_config.py` / `test_jobs_discover_cli.py`.

1. **Sin appname:** `jobs discover --source reliefweb` → exit **3**, **0** requests; mensaje enlaza a apidoc appname y menciona `[sources.reliefweb]` / `JOBBOT_RELIEFWEB_APPNAME`.
2. **403 appname:** fetcher con `error_403_appname.json` → exit **3**; stdout/logs **no** contienen el valor del appname.
3. **Dry-run mapeo:** fetcher `jobs_page1.json` + `--query "public health" --dry-run` → body con `query.value` + filtro de cierre vigente + appname en URL; filas con título/organismo/país/`closes_at`/URL; base sin cambios.
4. **Paginación:** `totalCount: 120`, page size 50, `--limit 100` → requests con `offset` 0 y 50.
5. **Remote:** título con «home-based» → `remote_type="remote"`.
6. **Env > toml:** `JOBBOT_RELIEFWEB_APPNAME` gana sobre `.jobbot.toml`.
7. **Offline:** suite sin red; RSS/web ReliefWeb fuera de alcance (anti-bot).

## Justificación

La API exige appname aprobado; hardcodearlo o usar el sitio/RSS viola términos y el UA. Config local + Guard exit 3 convierte el permiso en un contrato testeable; el mapeo a `closes_at` / organismo alimenta `jobs conditions` sin inventar hechos del perfil.
