## Contrato de tests (obligatorio en el PR)

Archivo sugerido: `tests/unit/test_browser_login_tour.py` (registro de empresas fixture; sin Chrome real).

1. **Buckets:** Active Workday y candidate Oracle aparecen; Greenhouse / Lever / Ashby (sin cuenta) no; `rejected` / `stale` / job boards no.
2. **Permanent needs_login:** sigue `needs_login` hasta evidencia de página firmada (`inspect_sessions`); un puerto CDP vivo no basta.
3. **Company tab:** una pestaña en el host de la empresa es `unknown`, nunca `ready`.
4. **Dry-run:** no lanza Chrome ni escribe `companies.yaml`.
5. **`--apply`:** abre solo el primer hueco y para; visitar un `candidate` no lo promueve.

## Justificación

Standing presence (#43) y signup (#44) asumen que ya se puede entrar. El tour tipa “dónde falta sesión” como plan auditable: lista, abre un portal, HITL humano para password/CAPTCHA/2FA — JobBot nunca inicia sesión solo.
