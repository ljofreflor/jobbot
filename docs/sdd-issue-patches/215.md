## Contrato de tests (obligatorio en el PR)

Archivo sugerido: `tests/unit/test_workday_cxs.py` (+ `test_jobs_from_url.py`; fetcher falso; sin red).

1. **parse_workday_url:** tabla con/sin locale, `wd1`/`wd3`/`wd5`/`wd103`, `/details/`; URL no Workday → `None`.
2. **Detalle abierto:** fixture `canApply: true` + `endDate` → `JobPosting` con título, empleador, URL canónica sin locale, `source_job_id` estable, `ats_kind=workday`.
3. **Cerrado:** 404 o 403 `S22` → `ClosedPostingError` con evidencia; el aviso no se guarda.
4. **406:** un reintento con `Accept`/`Content-Type` amplios; si persiste, error claro (no aviso vacío).
5. **Zona / time_unknown:** “23:59 Washington DC time” convierte a workspace; sin hora ni `closing_timezone` → fecha con `time_unknown` (nunca inventar hora).
6. **Integración:** `jobs add --url` y `jobbot get` sin `--file`/`--fixture` usan el mismo camino CXS (fetcher falso).

## Justificación

La ficha pública de Workday es una SPA sin descripción en el HTML; el contrato auditable es la API CXS pública + mapeo determinista a `JobPosting`, sin login y sin inventar zona de cierre.
