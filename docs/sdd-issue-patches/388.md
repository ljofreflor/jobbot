## Contrato de tests (obligatorio en el PR)

Archivo sugerido: `tests/unit/test_jobs_add_url_verify.py` (fixtures HTML bajo `tests/fixtures/`; sin red).

1. **Página de resultados / home:** fixture que no es ficha de cargo → **no** se guarda; el mensaje indica que no es el detalle (no HTTP live).
2. **Ficha con título y empleador:** fixture de detalle → se guarda; la URL persistida es la **final** del fixture (`final_url`); quedan `url_status` + `url_checked_at` (o campos equivalentes documentados en el modelo/repo).
3. **Host sin lector, sin `--file`:** no abre conexión de red; pide `--file` / `--stdin` (salvo caminos ya cubiertos: Workday #215, PDF según política existente).
4. **Cerrada / expirada (si el fixture lo marca):** no se guarda como aviso abierto (alineado con `ClosedPostingError` / check-open).

## Justificación

Una URL canónica incorrecta (SERP, home, id-only) contamina el shortlist y el paquete. Validar forma + semántica del HTML de ficha **antes** de `JobRepository.upsert` es el contrato que AGENTS.md ya exige al entregar URLs; #388 lo convierte en código testeable sin red.
