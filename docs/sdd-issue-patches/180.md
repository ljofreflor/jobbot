## Contrato de tests (obligatorio en el PR / hijos)

Fixtures por fuente bajo `tests/fixtures/<fuente>/`; `test_jobs_discover_cli.py` + `test_jobs_discover_greedy.py`; sin red.

1. **Fixture → JobPosting:** título, empleador, ubicación, URL canónica; `closes_at` (zona) y `salary_text` (tal cual; relleno → `None`) cuando vienen.
2. **Dry-run:** ningún `--source` escribe DB ni `companies.yaml`.
3. **Robots bloqueado:** mensaje claro + exit ≠ 0 + cero sockets extra.
4. **Fallas parciales:** un sitio caído no cancela a los demás; exit 0 si al menos uno respondió (#176).
5. **Dedupe:** `source` + `source_job_id`; no duplicar.
6. **`--greedy`:** catálogo fixture (ok / fail / blocked) + portal solo-perfil → informe con origen y estado por fila; sin escritura en dry-run; portal perfil encolable solo con campos públicos (#106).
7. **Catálogo sin adaptador ni blocked:** la prueba falla (todo portal del catálogo tiene adaptador o estado explícito).
8. **Domain-agnostic:** `test_domain_agnostic` verde.

## Justificación

`companies sites` vacío y scripts sueltos no cierran el ciclo learn → promote → discover. La épica tipa el comando común, el modo voraz con cobertura auditable y el mapeo de cierre/renta; los hijos implementan cada API pública sin login ni bypass.
