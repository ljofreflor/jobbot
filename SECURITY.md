# Security

JobBot keeps each candidate's profile, sessions and CV on their machine. The public
trust signal for this repository is the [OpenSSF Scorecard](https://scorecard.dev/viewer/?uri=github.com/ljofreflor/jobbot):
the Open Source Security Foundation (Linux Foundation) scores the supply chain,
including known vulnerabilities via OSV. That score is not self-certified.

## Reporting a vulnerability

Open a [GitHub security advisory](https://github.com/ljofreflor/jobbot/security/advisories/new)
or a private issue. Do not include real profiles, CVs, session files or tokens in the report.
